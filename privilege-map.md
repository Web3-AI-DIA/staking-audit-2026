# Privilege Map

| Function | Caller | Power |
|---------|--------|--------|
| stake | User | Deposit tokens |
| withdraw | User | Withdraw tokens |
| getReward | User | Claim rewards |
| setRewardRate | Owner | Change reward emission |
| rescueTokens | Owner | Withdraw arbitrary tokens |
| rewardPerToken | Anyone | View reward rate |
| earned | Anyone | View user rewards |
